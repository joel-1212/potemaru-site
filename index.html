まとめ

ぽてまるは、あなたのデータを外部に送信しません。歩数・体重・消費カロリーなどのヘルスケアデータも、アプリ内の記録も、すべてお使いのiPhoneの中だけで処理・保存されます。開発者がそれらを見ることはできません。外部に送るのは、初回に1回だけお聞きする「どこで知ったか」の答えだけです（下の「初回アンケート」）。

取得する情報

アプリは、あなたが許可した場合にかぎり、iOSのヘルスケアから次のデータを読み取ります。書き込みは行いません。

  • 歩数 — キャラクターの成長と体型に反映するため
  • 歩行距離・消費カロリー・体重 — 週ごとの振り返りレポートを作るため

これらは端末内でのみ処理され、外部のサーバーに送信されることはありません。許可はいつでもiOSの「設定 → プライバシーとセキュリティ → ヘルスケア」から取り消せます。

アカウント

アカウント登録はありません。氏名・メールアドレス・電話番号などを取得することはありません。

保存される場所

目標歩数、キャラクター、きせかえ、コイン残高、週ごとの集計などは、端末内の保存領域に置かれます。アプリを削除すると、これらのデータも消えます。開発者が復元することはできません。

広告・解析

広告は表示しません。行動解析ツールや第三者のトラッキングSDKは組み込んでいません。

初回アンケート（利用状況の集計）

初回起動時に「このアプリをどこで知ったか」を1回だけお聞きします。選んだ項目（答えなかった場合は「答えなかったこと」）、押した選択肢の表示位置（選択肢の並びは端末ごとに入れ替えて表示します）、画面が出てから回答までの秒数、アプリ名、端末の種類（iOS / Web）、アプリの版、日付のみを、開発者の集計用スプレッドシート（Google LLC が提供するサービス上）に送信します。端末の識別子・氏名・メールアドレス・位置情報などの個人を特定する情報は送信しません。回答は任意です。「答えずに始める」を選んだ場合も、答えなかったことを上の項目と一緒に送信します（回答率を知るためです）。集計はアプリの告知先を決める目的にのみ使い、第三者に提供しません。

課金について

アプリ内課金の処理はAppleおよびRevenueCat社（購入状態の管理）を通じて行われます。この過程で、購入の有無を識別するための匿名のID（Appleが発行する購入トークン等）が扱われます。氏名・住所・カード情報などの支払い情報は、Appleが管理し、開発者に共有されることはありません。

  • RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy/

子どものプライバシー

13歳未満の方から意図的に情報を取得することはありません。そもそも個人を識別する情報を取得しない設計です。

健康に関するご注意

本アプリは健康・医療上の助言を行うものではありません。表示される歩数・距離・消費カロリー等はiOSのヘルスケアが記録した値であり、その正確性は端末やウェアラブル機器の測定精度に依存します。体調に関する判断は医療専門家にご相談ください。

サブスクリプション（ぽてまる Pro）

  • ぽてまる Pro は、毎週の振り返りレポートを利用できる自動更新サブスクリプションです。
  • 価格: 月額 400円 または 年額 2,000円（日本ストア・税込）
  • はじめてご利用の方には1か月の無料お試しがあります。無料お試しは1つのサブスクリプショングループにつき1回のみです。
  • 期間終了の24時間前までに解約されない場合、同額で自動更新されます。
  • 解約は、iPhoneの「設定 → Apple ID → サブスクリプション」から行えます。無料お試し期間中に解約された場合、料金は発生しません。
  • 無料お試し期間が残っている状態で購入された場合、残りの無料期間は失効します。

コイン

  • コインはアプリ内のきせかえと交換できる消耗型のアイテムです。現金への換金はできません。
  • コインは歩くことで無料でも貯まります。課金は、早く手に入れたい方向けの任意の手段です。
  • キャラクターの成長・進化・たまごの入手は、歩数によってのみ進みます。課金では進みません。
  • アプリを削除すると、端末内のデータとともにコイン残高も失われます。
